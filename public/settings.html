Environment configuration

Secrets belong in your hosting provider's environment settings, never in source code or browser JavaScript.

DISCORD_TOKENRequiredBot token from the Discord Developer Portal. Keep private.
CLIENT_IDRequiredDiscord application's Application ID.
DASHBOARD_CLIENT_SECRETRequired for loginOAuth2 client secret from the same Discord application.
DASHBOARD_REDIRECT_URIRequired for loginExact public URL ending in /auth/callback.
DASHBOARD_SESSION_SECRETRequired for loginUse a long random secret generated by your hosting provider or password manager.
DASHBOARD_ADMIN_IDSOptionalComma-separated Discord user IDs allowed to view manageable servers regardless of individual server permissions.
PORTUsually provided by hostThe dashboard listens on 0.0.0.0 and respects the host's PORT value.
SECURITY NOTES

Before publishing

  • Use HTTPS and set the OAuth redirect URI to the exact deployed address.
  • Do not commit .env files, bot tokens, OAuth secrets or session secrets.
  • Configure persistent storage or a database before relying on economy balances.
  • Keep the service on a host that supports long-running Node.js processes; GitHub Actions checks code but does not keep the bot online.
